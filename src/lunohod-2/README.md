# Lunohod-2

Differential drive autonomous mobile robot with SLAM and navigation capabilities.

## Overview

Lunohod-2 is a ROS2-based autonomous mobile robot featuring:
- Differential drive chassis with micro-ROS controller
- RPLidar C1 2D lidar sensor
- Integrated IMU and wheel encoders
- Two operation modes: Map Building and Navigation

## Quick Start

### Build the Package
```bash
cd /workspaces/ros-pg
colcon build --packages-select lunohod-2
source install/setup.bash
```

### Map Building Mode
```bash
ros2 launch lunohod-2 mapping_mode.launch.py
```

### Navigation Mode
```bash
ros2 launch lunohod-2 navigation_mode.launch.py map:=/path/to/map.yaml
```

## System Requirements

- ROS2 Kilted
- micro-ROS agent
- Nav2 navigation stack
- slam_toolbox
- robot_localization
- RPLidar C1 driver (sllidar_ros2)

## Hardware

- Differential drive chassis with micro-ROS firmware
- RPLidar C1 2D lidar
- IMU (integrated with chassis)
- Camera (optional, for teleoperation only)

## Topics

### Published by Hardware
- `/ugv/odom` - Wheel odometry (50 Hz)
- `/ugv/imu` - IMU data (50 Hz)
- `/ugv/encoder` - Encoder data (50 Hz)
- `/scan` - Lidar scans (~10 Hz)

### Subscribed by Hardware
- `/ugv/cmd_vel` - Velocity commands

### Generated by Software
- `/odometry/fused` - EKF-fused odometry
- `/map` - Occupancy grid map
- `/tf` - Transform tree
